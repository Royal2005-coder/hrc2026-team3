# Kiểm Tra Camera

## Vai trò

Thư mục này chứa bằng chứng về camera runtime và geometry phục vụ nhánh semantic final.

## File nên đọc trước

- `camera_inventory.csv`
  - bảng kiểm tra 4 camera runtime
- `camera_config_sheet.csv`
  - bảng cấu hình camera dùng cho handoff
- `camera_geometry.json`
  - geometry, intrinsics và pose runtime đã thu được
- `base_transform_runtime.json`
  - evidence cho base frame runtime
